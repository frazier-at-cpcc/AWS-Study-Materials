# AWS Study Materials

Condensed **study notes** and printable **cheat sheets** for two AWS Academy courses —
one of each per module, built for fast review and exam readiness.

**📖 Browse online:** https://frazier-at-cpcc.github.io/AWS-Study-Materials/

Each module ships two documents:

- **Cheat Sheet** — 2–3 pages, dense datasheet: must-know facts, key terms, comparison
  tables, exam traps, and a self-quiz with answer key.
- **Study Notes** — 4–8 pages, textbook style: full section-by-section coverage with key
  concepts, common pitfalls, worked examples, a one-page summary, and review questions.
